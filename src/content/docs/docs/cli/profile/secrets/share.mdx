import { Badge } from '@astrojs/starlight/components';

Sets how a profile shares its secrets with GitHub, and copies every secret there.

```sh
taylr profile secrets share organization
```

- **`organization`** stores the secrets on your profile's GitHub organization and gives your
  existing repositories access.
- **`repository`** stores them on each of your repositories.
- **`skip`** stops copying them, and prints the secrets list and the commands to set them
  yourself.

See [Set up CI secrets](/docs/guides/ci-secrets/) to choose. The choice is saved as `github.ciSecrets`
in the [profile](/docs/cli/profile/#editing-a-profile).

Without a mode, it keeps the current one and copies every secret to GitHub again, for example
after someone deleted one on GitHub:

```sh
taylr profile secrets share
```

## Arguments

### mode <Badge text="Optional" />

`organization`, `repository` or `skip`. Default: the profile's current `github.ciSecrets`.

```sh
taylr profile secrets share [mode]
```

### profile <Badge text="Optional" />

The profile whose secrets to share. Default: your [default profile](/docs/cli/profile/default/).

```sh
taylr profile secrets share --profile [profile]
```

### no-interactive <Badge text="Optional" />

Don't ask questions, such as for GitHub sign-in. Fails if the [GitHub CLI](https://cli.github.com)
isn't signed in.

```sh
taylr profile secrets share --no-interactive
```
