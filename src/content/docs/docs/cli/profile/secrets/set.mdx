---
title: taylr profile secrets set
description: Add or replace a profile's App Store Connect API key, certificates password, or the key to your certificates storage.
---

import { Badge } from '@astrojs/starlight/components';

Saves a secret in your macOS Keychain and copies it to GitHub, as the profile
[shares its secrets](/docs/cli/profile/secrets/share/). Use it to add a secret you skipped
in [`taylr profile add`](/docs/cli/profile/add/), or to rotate one.

```sh
taylr profile secrets set api-key ~/Downloads/AuthKey_ABC123DEFG.p8
taylr profile secrets set match-password
taylr profile secrets set match-deploy-key ~/.ssh/acme_certs_deploy
taylr profile secrets set match-storage-key ~/Downloads/acme-certs-sa.json
```

- **`api-key`** reads your App Store Connect API key from its `.p8` file. The key ID comes
  from the file's name; taylr asks for the issuer ID.
- **`match-password`** asks for the password that encrypts your certificates repository,
  without showing it.
- **`match-deploy-key`** reads the private half of a read-only deploy key for your
  certificates repository. GitHub's runners need it to clone an SSH certificates repository.
  [`taylr profile add`](/docs/cli/profile/add/) creates one for you; use this to bring your
  own, or when you can't add deploy keys to the repository yourself.
- **`match-storage-key`** is the access key for [certificates kept in cloud
  storage](/docs/cli/profile/#certificates-storage). For S3, taylr asks for the access key ID
  and secret. For Google Cloud Storage, give the service account's JSON key file. For GitLab,
  taylr asks for an access token.

## Arguments

### secret <Badge text="Required" variant="caution" />

`api-key`, `match-password`, `match-deploy-key` or `match-storage-key`.

```sh
taylr profile secrets set <secret>
```

### path <Badge text="Optional" />

For `api-key`, the `.p8` file. For `match-deploy-key`, the private key file. For
`match-storage-key` with Google Cloud Storage, the JSON key file. Required for these.

```sh
taylr profile secrets set api-key <path>
```

### issuer-id <Badge text="Optional" />

For `api-key`, the issuer ID from App Store Connect → Users and Access → Integrations. Without
it, taylr asks. Required with `--no-interactive`.

```sh
taylr profile secrets set api-key <path> --issuer-id [issuer-id]
```

### profile <Badge text="Optional" />

The profile to save the secret in. Default: your [default profile](/docs/cli/profile/default/).

```sh
taylr profile secrets set <secret> --profile [profile]
```

### no-interactive <Badge text="Optional" />

Don't ask questions. `match-password` reads the password from standard input.

```sh
echo "$MATCH_PASSWORD" | taylr profile secrets set match-password --no-interactive
```
