Renews the App Store session (`FASTLANE_SESSION`), which expires about once a month. taylr
signs in to App Store Connect, with two-factor authentication if needed, saves the new session
in your Keychain and copies it to GitHub.

```sh
taylr profile secrets renew-session
```

Only [`taylr project privacy`](/docs/cli/project/privacy/) needs the session.
[`taylr profile list`](/docs/cli/profile/list/) warns you when it is close to expiring, and a
weekly workflow in your project warns you when it has expired.

It always asks you to sign in, so it has no `--no-interactive`.

## Arguments

### profile <Badge text="Optional" />

The profile whose session to renew. Default: your [default profile](/docs/cli/profile/default/).

```sh
taylr profile secrets renew-session --profile [profile]
```
