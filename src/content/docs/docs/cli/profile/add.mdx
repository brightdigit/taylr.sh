Creates a [profile](/docs/cli/profile/). It asks a few questions and saves your answers in
[`~/.taylr/profiles/<name>/profile.yml`](/docs/cli/profile/#editing-a-profile), where you can edit them later. Next to it, it writes
`header.mustache`, the [file header](/docs/cli/profile/#file-header) for new projects. Your first
profile becomes the default.

```sh
taylr profile add client-x
```

[`taylr project create`](/docs/cli/project/create/) runs this for you when you have no
profile yet.

## Before the questions

taylr first checks the tools it needs (see [Installation](/docs/getting-started/installation/#requirements)):

```text
◆ mise           Not installed.                          Install with Homebrew / Skip
◆ GitHub CLI     Not signed in.                          Sign in now / Skip
◆ GitHub access  Allow access to organization secrets?   Yes / Skip
```

- taylr asks only about what's missing. When everything is ready, it goes straight to the
  questions.
- **Install** uses Homebrew, or mise for the GitHub CLI if you don't use Homebrew.
- **Sign in** runs `gh auth login`. **GitHub access** runs `gh auth refresh -s admin:org`,
  which lets taylr set [organization secrets](/docs/guides/ci-secrets/).
- **Skip** carries on. Answers that need the GitHub CLI (finding your organization, creating
  the certificates repository and its deploy key, sharing CI secrets) become "Later".

With `--no-interactive`, taylr doesn't install anything. If a value you passed needs a
missing tool, it stops before doing anything and prints the command to run.

## The questions

```text
◆ Organization   What's your organization's name?        Acme Corp
◆ Bundle IDs     Bundle ID prefix?                       com.acmecorp  ✓ / edit
◆ Team           Apple Developer Team ID?                ABCDE12345  (found in Xcode) / Later
◆ Apple ID       Apple ID for App Store Connect?         dev@acme.com / Later
◆ ASC team       App Store Connect team ID?              Acme Corp (1234567) / Later
◆ Certificates   Git repository for your certificates?   Create acme/certificates / Use existing / Later
◆ GitHub         GitHub organization?                    acme        (found with gh)
◆ Runners        Where should macOS CI jobs run?         By visibility / Self-hosted / GitHub-hosted
◆ API key        Add your App Store Connect API key?     Add now / Later
◆ CI secrets     Share secrets with your GitHub repos?   Organization / Per repo / Skip
◆ Saved          Profile "client-x"
```

- Only the **organization** is required. taylr asks for everything else that has no
  default, and shows where to find it (see below). Answer "Later" if you don't have it yet.
  A command that needs a missing value stops before doing anything and tells you which key to
  add to the [profile file](/docs/cli/profile/#editing-a-profile). It never asks partway
  through.
- **Defaults:** a value already in `profiles:` in [`~/.taylr/config.yml`](/docs/cli/profile/#defaults)
  is suggested, and kept there rather than copied if you accept it, so changing it later
  changes every profile that uses it.
- **Bundle IDs**: the prefix is suggested from your organization's name. Apps you create
  get bundle IDs like `com.acmecorp.Acme`.
- **Found in Xcode / found with gh:** taylr suggests values it can detect, and you always
  confirm them. Detecting your team from Xcode is experimental and only works on a Mac where
  you're signed in to Xcode.
- **Runners**: self-hosted runners are your own Macs, registered with GitHub and labeled
  `self-hosted` and `macOS`. GitHub-hosted runners need no setup, and are free for public
  repositories. **By visibility** (the default) uses your Macs for private repositories and
  GitHub's for public ones. It's saved as the profile's
  [project default](/docs/cli/profile/#project-defaults) `projects.ci.runners`.
- **API key** and the certificates password go into your macOS Keychain, never into a file.
  Choose "Later" and add the key with [`taylr profile secrets set`](/docs/cli/profile/secrets/set/).
- **CI secrets** picks how the secrets reach GitHub. See
  [Set up CI secrets](/docs/guides/ci-secrets/). Change it later with
  [`taylr profile secrets share`](/docs/cli/profile/secrets/share/).

### Where to find each answer

| Question | Where it comes from |
| --- | --- |
| Team | [developer.apple.com/account](https://developer.apple.com/account) → Membership details. taylr suggests it if you're signed in to Xcode. |
| Apple ID | The email address you sign in to App Store Connect with. |
| ASC team | taylr signs in with your Apple ID and lists your App Store Connect teams to pick from. You only need this if you belong to more than one. |
| Certificates | A private Git repository that holds your encrypted code-signing certificates. taylr can create an empty one in your GitHub organization, or you can name one you already use. Either way, taylr adds a read-only deploy key to it, so GitHub's runners can clone it. To keep them in S3, Google Cloud Storage or GitLab instead, choose "Later" and set [`signing.storage`](/docs/cli/profile/#certificates-storage) in the profile file. |
| API key | App Store Connect → Users and Access → Integrations → App Store Connect API. taylr opens the page and asks for the downloaded `.p8` file and the issuer ID. |

## Arguments

### name <Badge text="Optional" />

The profile's name (`name`), and the name of its folder in `~/.taylr/profiles/`. Default:
`default`.

```sh
taylr profile add [name]
```

### no-interactive <Badge text="Optional" />

Don't ask questions. Values come from the arguments below, and `--organization` is required.

```sh
taylr profile add --no-interactive
```

### organization <Badge text="Optional" />

Your organization's name.

```sh
taylr profile add --organization [organization]
```

### bundle-id-prefix <Badge text="Optional" />

The start of every bundle ID. Default: `com.` followed by your organization's name in lowercase,
without spaces or punctuation.

```sh
taylr profile add --bundle-id-prefix [bundle-id-prefix]
```

### team-id <Badge text="Optional" />

Apple Developer Team ID (`apple.teamID`).

```sh
taylr profile add --team-id [team-id]
```

### apple-id <Badge text="Optional" />

Apple ID for App Store Connect (`apple.appleID`).

```sh
taylr profile add --apple-id [apple-id]
```

### asc-team-id <Badge text="Optional" />

App Store Connect team ID (`apple.ascTeamID`).

```sh
taylr profile add --asc-team-id [asc-team-id]
```

### certs-repo <Badge text="Optional" />

Git repository for your code-signing certificates (`signing.storage.git`).

```sh
taylr profile add --certs-repo [certs-repo]
```

### github-org <Badge text="Optional" />

GitHub organization (`github.org`).

```sh
taylr profile add --github-org [github-org]
```

### github-visibility <Badge text="Optional" />

`private` or `public`, for repositories taylr creates (`projects.github.visibility`). Default:
`private`.

```sh
taylr profile add --github-visibility [github-visibility]
```

### ci-runners <Badge text="Optional" />

Where new projects' macOS CI jobs run: `github-hosted` or `self-hosted`
(`projects.ci.runners`). Default: self-hosted for private repositories, GitHub-hosted for
public ones.

```sh
taylr profile add --ci-runners [ci-runners]
```
